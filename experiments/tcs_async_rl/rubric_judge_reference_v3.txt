Distinguish mathematical gaps from harmless slips. A proof with a strictly negative limiting exponent establishes an eventual fixed negative rate even if its last displayed line reuses the limiting gap where half that gap is needed. This elementary constant-slack correction does not supply a new proof mechanism. A false threshold-existence claim is a different substantive scope error. A recurrence with linear combine work cannot be declared linear by ignoring a resonant logarithmic factor. Sparsity alone does not prove one arithmetic problem reduces to another.

Use elementary bit complexity at its proper level. If an argument bounds all inputs by polynomial bit length, a polynomial number of exact rational additions and comparisons has polynomial bit cost. It need not provide an implementation of rational addition. It must still control those input lengths and the number of operations.
